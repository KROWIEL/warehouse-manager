## [1.0.0] — 2026-11-06

Первый публичный релиз.

### Возможности

- Аккаунты из `.env`, принудительная смена пароля при первом входе, профиль с аватаром и темой.
- Категории, подкатегории, поставщики, настраиваемые поля товара (select / text).
- Товары со штрихкодом, остаток через журнал движений: приход, продажа, возврат, списание, инвентаризация.
- Продажи чеками: несколько позиций, скидка, оплата, клиент, торг по цене, возвраты.
- Статистика за скользящий период или свой диапазон, разрезы, динамика, низкие остатки и мёртвый сток.
- Экспорт статистики в Excel (15 листов с графиками) и скачивание бэкапа базы.
- PWA и сканер штрихкодов камерой, в том числе на iOS.
- Развёртывание одним `docker compose up`, автоматический HTTPS через Caddy.

### Безопасность

- Пароли: PBKDF2-SHA256. До смены стартового пароля API закрыт.
