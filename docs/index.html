Что внутри

Всё, что нужно небольшому магазину, без CRM на триста экранов.

1

Каталог под ваш товар

Категории, подкатегории и поля, которые вы сами задаёте: размер, цвет, надпись — или что угодно ещё.

2

Склад с историей

Остаток считается из движений: приход, продажа, возврат, списание, инвентаризация. Ничего не теряется.

3

Продажи чеками

Несколько позиций, скидка, оплата, клиент, торг по цене. Сканер штрихкодов работает и на iPhone.

4

Статистика и Excel

Разрезы по поставщикам, категориям и полям товара. Экспорт на 15 листов с живыми графиками.

5

PWA на телефон

Ставится на домашний экран. Нижняя навигация, тёмная и светлая тема.

6

Без регистрации

Аккаунты из конфига. При первом входе — строгий пароль, до этого данные закрыты.

Склад, продажа, статистика и настройки — светлая тема, тёмная и телефон.

Быстрый старт

Локально за пару команд. На сервере — тот же образ плюс Caddy с HTTPS.

# клон и локальный запуск
git clone https://github.com/KROWIEL/warehouse-manager.git
cd warehouse-manager
cp .env.example .env
docker compose -f docker-compose.local.yml up -d --build

# открыть http://localhost:8080
  1. Заполните `.env` — логины и одноразовые пароли продавцов.
  2. Войдите — приложение потребует задать строгий пароль.
  3. На сервере укажите DOMAIN и ACME_EMAIL, затем docker compose up -d --build.
  4. Сканер проверяйте по HTTPS — по локальному IP камера не включится.
